# Included surface materials

These materials are distributed under **CC0 1.0** by [Poly Haven](https://polyhaven.com/license).
No account, API key, or runtime network request is required.

| Material | Use | Included maps |
|---|---|---|
| [Plastered Wall 02](https://polyhaven.com/a/plastered_wall_02) | Walls and ceilings | 1K colour, OpenGL normal, roughness |
| [Wooden Floor 02](https://polyhaven.com/a/wooden_floor_02) | Wooden floors and surfaces | 1K colour, OpenGL normal, roughness |
| [Floor Tiles 06](https://polyhaven.com/a/floor_tiles_06) | Kitchen and bathroom floors | 1K colour, OpenGL normal, roughness |

The nine original JPEG maps total 3,874,541 bytes. Source URLs, byte sizes and SHA-256
checksums are recorded in `download-manifest.json`. The images are unmodified.

Run `python scripts/download_materials.py --check` to verify the library.
Run `python scripts/download_materials.py` to restore a missing or modified file.

Furniture remains procedural, with components sized to the measured footprint.
No third-party furniture models or HDRIs are required or included.
